# Bela Agenda (Python Version)

Sistema de agendamento de salão desenvolvido em Python. 

## Fase 0: Estrutura Inicial (Agosto/2026)

Nesta primeira fase de desenvolvimento, o sistema foi estruturado para consolidar o uso de estruturas de dados fundamentais em Python.

### Funcionalidades Implementadas

*   **Estrutura de Dados:** Armazenamento de informações de usuários, serviços e agendamentos utilizando dicionários e listas.
*   **CRUD Básico:** Funções implementadas para criar e listar dados.
*   **Menu Interativo:** Navegação via terminal para o usuário acessar todas as opções do sistema.
*   **Persistência Simples:** Carregamento e salvamento dos dados localmente no formato JSON.

*(POO e arquiteturas avançadas serão integradas nas próximas fases do projeto).*
